# Lab 004：触摸输入

Bevy 使用 `Touches` Resource 保存当前所有触摸点的状态。一个触摸点有唯一的 `id`，并且会经历开始、移动、结束或取消几个阶段，因此可以同时处理多个手指。

## 使用 `Touches` 查询触摸点

系统可以遍历不同阶段的触摸点：

- `iter_just_pressed()`：本周期刚开始的触摸；
- `iter()`：当前仍然存在的触摸点；
- `iter_just_released()`：本周期刚结束的触摸；
- `iter_just_canceled()`：系统取消追踪的触摸，例如窗口失去焦点。

每个 `Touch` 都可以读取：

- `id()`：触摸点编号；
- `position()`：当前屏幕位置；
- `delta()`：相对上一个周期的位置变化；
- `start_position()`：开始触摸的位置。

触摸点的编号可能在结束后被系统重新使用，所以不能把同一个编号永久当作同一根手指。需要处理每次底层触摸阶段消息时，也可以使用 `MessageReader<TouchInput>`；一般只关心当前状态时，读取 `Touches` 就足够了。

## 示例如何运行

```bash
nix develop
just run input 004
```

在支持触摸的窗口或设备上触摸并移动手指，结果会打印到终端。按 `Escape` 退出。普通桌面环境没有触摸设备时，程序仍可运行，只是不会产生触摸输入。
