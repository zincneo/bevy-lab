# Image assets

`bevy-icon.png` is copied from the Bevy repository's `assets/branding/icon.png` for the image-loading lab.

`bevy-bird-dark.png` is copied from the Bevy repository's `assets/branding/bevy_bird_dark.png`.

The example loads these files through the asset-relative paths `images/bevy-icon.png` and
`images/bevy-bird-dark.png`. The second file is loaded only after the example's button is
activated.
